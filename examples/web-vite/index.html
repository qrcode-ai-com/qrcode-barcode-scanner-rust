Scan a QR code or a barcode from an image, in your browser. The image is decoded on this device by a WebAssembly module: it is never uploaded. Decoded links are shown as text and never opened.

The QR code scanner and the barcode scanner are QR Code AI’s own scanning pages. To add this engine to your code, start with the QR code scanner SDK guide or the barcode scanner SDK guide, which cover every runtime. To make a test image with a known payload, use the QR code generator or the barcode generator, then compare the scan with the value you encoded.

How it works

The browser package works in three steps: install and initialize it, pass an image or a camera frame to the engine in the page, then read the report. This page does the same with the image you choose below: its worker loads the published WebAssembly package, scans the image and shows the report.
