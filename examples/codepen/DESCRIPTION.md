Scan QR codes and barcodes in your browser with the open-source QR Code & Barcode Scanner. This Pen loads the published WebAssembly package @qrcode-ai-com/qrcode-barcode-scanner-wasm 0.12.0 from jsDelivr at that exact version, checks the module's SHA-256, then scans a sample image that holds a QR code and a Code 128 barcode in the fast, frame and full profiles. Drop your own image to scan it: it is decoded on your device and never uploaded.

The [QR code scanner](https://qrcode-ai.com/en-US/qr-code-scanner) and the [barcode scanner](https://qrcode-ai.com/en-US/barcode-scanner) are QR Code AI's scanning
pages in the browser. The Pen uses the browser package, which has the
[QR code scanner JavaScript guide](https://qrcode-ai.com/en-US/qr-code-scanner/sdk/javascript) and the
[barcode scanner JavaScript guide](https://qrcode-ai.com/en-US/barcode-scanner/sdk/javascript). To make a test image with a known value, use the
[QR code generator](https://qrcode-ai.com/en-US/qr-code-generator) or the [barcode generator](https://qrcode-ai.com/en-US/barcode-generator), drop the exported image on
the Pen and compare the decoded text with the value you encoded.

## How it works

![How the browser package works, in three steps: install and initialize, pass an image or a camera frame to the engine in the page, and read the report](https://raw.githubusercontent.com/qrcode-ai-com/.github/main/profile/assets/how-browser-light.gif?v=248e5382e6cc)

The Pen follows the three steps of the browser package. It loads the published WebAssembly module
from jsDelivr and checks it, passes the bytes of an image to the engine in a worker, and reads the
report it gets back.

## What it returns

![A QR code and Code 128 decoded from the same image, each outlined where the engine measured it](https://raw.githubusercontent.com/qrcode-ai-com/qrcode-barcode-scanner-rust/main/docs/assets/brand/examples-mixed-light.png?v=7f958679adcc)

The picture is a recorded scan of the Pen's sample image, which holds a QR code and a Code 128
barcode. Both come back in one report, each with its format, its exact text and the place where the
engine measured it: `https://qrc-ai.com/76xMa` and `STOCK-4827`.

## What it reads

![The code families the engine reads: QR codes, matrix and stacked codes such as Data Matrix, retail barcodes such as EAN-13, and other linear barcodes such as Code 128](https://raw.githubusercontent.com/qrcode-ai-com/qrcode-barcode-scanner-rust/main/docs/assets/brand/formats-light.gif?v=bdfe5fc5f9b3)

- QR: QR Code, Micro QR, rectangular Micro QR (rMQR)
- Matrix and stacked: Data Matrix, Aztec, PDF417, MaxiCode
- Retail: EAN-13, EAN-8, UPC-A, UPC-E
- Other linear: Code 128, Code 39, Code 93, Codabar, ITF, GS1 DataBar, GS1 DataBar Expanded, Telepen

The engine reads PNG, JPEG, WebP or GIF images. Codes of different formats in one image come back in
one report. The engine's [supported formats](https://github.com/qrcode-ai-com/qrcode-barcode-scanner-rust#supported-formats) section states the known
limits.

## The same engine in other runtimes

![One engine in the language you write: Rust on crates.io, Node.js and the browser on npm, Python on PyPI, Go, PHP, and the qrscan command line](https://raw.githubusercontent.com/qrcode-ai-com/qrcode-barcode-scanner-rust/main/docs/assets/brand/runtimes-light.png?v=6dbd5a8cf5ba)

The Rust, Node.js, browser and Python packages hold the engine. The Go and PHP packages hold no
decoder: each one starts `qrscan` and hands you its report. Every route is listed in the
[scanner repository](https://github.com/qrcode-ai-com/qrcode-barcode-scanner-rust).
